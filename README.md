# Impulse for Mac

Official app downloads and the signed update feed for Impulse, your iPhone AI companion’s connection to your Mac.

Download the latest DMG from [Releases](https://github.com/benno-sawitzki/impulse-releases/releases/latest), drag Impulse into Applications, and open it. Existing installations with the updater can choose **Check for Updates…** from the waveform menu.

The developer preview supports macOS 14.2 or later on Apple silicon and Intel. It is Apple Development signed and is not yet notarized. macOS may require its normal approval on first installation.

This repository contains downloadable app builds and update metadata. It does not contain user data, credentials, or private source code.
